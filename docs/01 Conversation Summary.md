# Conversation summary — "Analog Neuron Tapeout Plan"

Source: [Analog Neuron Tapeout Plan.md](Analog%20Neuron%20Tapeout%20Plan.md) (ChatGPT conversation, 13 user turns).
Summarised 2026-11-08.

## Established project goals (net result of the conversation)

1. **Area goal:** show that an analog neuron can be made in much less silicon than a comparable, process-matched digital neuron. Report both core area and effective area (core + local configuration + amortised shared infrastructure).
2. **Fidelity goal:** measure the *marginal hardware cost of biological fidelity*: LIF → AdEx → passive dendrites → active dendrites, i.e. ΔArea per new behaviour.
3. **Platform goal:** build a reproducible characterisation platform. It should support programmability, reproducibility, capacitance and speed scaling, probe-loading controls, and a digital reference.
4. **Scaling goal (added late):** prepare for the whole-brain programme. *Parameter economy* is a first-class metric: how few per-neuron variables, and how much fixed (hard-coded) parameterisation, make a population usable.
5. **Coverage before replication.** First cover the full experimental range, then spend spare area on replication.
