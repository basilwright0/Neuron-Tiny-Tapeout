# neuron_ctrl configuration map (rev E: write-only latches)

RTL: `rtl/neuron_ctrl.v` (top), `rtl/nc_cfg.v` (config port), `rtl/nc_sync.v` (sync, reset bridge, latch and clock-gate cells), `rtl/digital_lif.v`.
Addresses and the `cfg_out` packing live in `rtl/nc_regmap.vh` and are mirrored in `test/regmap.py`.
The bias_b1 control ports are generated by `rtl/scripts/gen_bias_if.py` (→ `rtl/nc_bias_ports.vh`, `rtl/nc_bias_if.vh`), which takes their names and order from `cells/bias/bias_b1.spice` (rev C).

**Rev E vs rev D** (same write protocol, **new addresses**; `docs/08 Updated Plan.md` §5):
- the SC clock divider is gone (no `sc_clk` port, no SC_DIV bits); LIF_EN / LIF_SRC moved to byte LIF_CTL;
- bias_b1 rev C has a fixed range per current DAC: the RANGE bits and the range decode are gone. The eight 5-bit current-DAC codes are packed into 5 bytes and the one voltage-DAC code takes 1 byte (§3.2);
- `TRIM_MASK` defaults to 16'hC1FD: only trim nibbles 0, 2–8, 14 and 15 have storage;
- spike channel 3 is now **AdEx**, outside the array, with its own probe line `probe_sel_adex`; array slot (0,3) (formerly P1) is a dummy and can never be selected (§3.1).

Kept: the digital LIF (12 bit), the row × column probe select, D1_BSEL, D1_CHAIN, IB_X2, OUT_MUX, the config protocol.
Rev B (SPI register file with read-back, counter, spike muxes) is preserved in `rtl/revB/` and `test/revB/`.

The chip keeps only the configuration storage, the probe decoder and the digital LIF. Everything else (spike timestamping and counting, tick generation, sequencing, read-back of state) is done by the demo-board RP2040/RP2350 (PIO).

Every byte resets to **0**, and all-zero means "everything off": every DAC code 0 (off), bias off, all groups disabled, probe off, rt pass-through off, digital LIF disabled, OUT_MUX = 0.

## 1. Pins

| Pin | Dir | Signal |
|---|---|---|
| ui[0] | in | **SCK**: config shift clock (rising edge) |
| ui[1] | in | **DATA**: config serial data, MSB first |
| ui[2] | in | **LOAD**: config latch strobe (high = write) |
| ui[3] | in | stim A: `rt_out[0]`; LIF event source 0 |
| ui[4] | in | stim B: `rt_out[1]`; LIF event source 1 |
| ui[5] | in | hold: `rt_out[2]` |
| ui[6] | in | membrane reset: `rt_out[3]` |
| ui[7] | in | **LIF tick**: one digital-LIF update per rising edge |
| uo[7:0] | out | spikes of analog neurons 0..7 (combinational, buffered) |
| uio[5:0] | out | spikes of analog neurons 8..13 (combinational, buffered) |
| uio[6] | out | OUT_MUX = 0: digital-LIF spike (1-clk pulse); OUT_MUX = 1: neuron 14 |
| uio[7] | out | OUT_MUX = 0: config echo (shift-register MSB); OUT_MUX = 1: neuron 15 |

`uio_oe` = 0xFF (all uio pins are outputs). `uio_in` is unused.
`rt_out` = `ui_in[6:3]` & RT_EN, combinational.

## 2. Write protocol

- **Frame:** 13 bits `{ADDR[4:0], DATA[7:0]}`, MSB first. DATA is sampled on each SCK rising edge into a 13-bit shift register (clocked directly by the pin; no clk needed, no oversampling).
- **Only the last 13 bits before LOAD count.** A PIO can therefore send 16-bit words with 3 leading don't-care bits (tested), or any longer stream.
- **Write:** pulse LOAD high. While LOAD is high, the latch byte `ADDR` is transparent and takes `DATA`; LOAD falling closes it. Exactly one byte changes, once (tested with LOAD widths of 10 ns to 500 ns).
- **SCK with LOAD low never writes** (tested with 200 random bits).
- Writes to unused addresses (0x17..0x1F) and to bits without storage are ignored.
- There is no read-back. Link check: with OUT_MUX = 0, uio[7] = shift-register MSB, so every bit shifted in reappears on uio[7] 13 SCK rising edges later (it changes just after each SCK rising edge; sample it before the next one). Before the first 13 SCK edges after power-up the echo is undefined (the shift register has no reset).
- The config port and latches do not use clk; they work with clk stopped (tested).
- **Reset:** `rst_n` low clears every latch asynchronously (directly from the pin, no clk needed). LOAD has no effect while `rst_n` is low.

### Timing contract (host)

```
          ___     ___           ___                                   ___
SCK   ___|   |___|   |__ ... __|   |_________________________________|   |__
      <D12 ><D11 >      ...  <D0  >
DATA  ======X=====X=====...==X=====X==================================X====
                                    |<-t_su->|_____________|<-t_h->|
LOAD  ______________________________________|  t_load      |__________________
                                             latch[ADDR] transparent
```

| Requirement | Min | Notes |
|---|---|---|
| SCK high, SCK low | 20 ns | simulated down to 10 ns |
| DATA setup / hold to SCK rising | 5 ns | |
| t_su: last SCK rising → LOAD rising | 50 ns | decode settles (simulated at 20 ns) |
| t_load: LOAD high | 50 ns | simulated 10 ns..500 ns |
| t_h: LOAD falling → next SCK rising | 50 ns | latch closes before the frame moves |

The latch enable is `le[a] = LOAD & (sr[12:8] == a)`. Because SCK has no edge from t_su before LOAD rises until t_h after LOAD falls, the address decode and the latch D inputs are static whenever LOAD can be 1; each `le` is then an AND of a static level with one pin, which cannot glitch. The 50 ns figures leave margin for pad/TT-mux delay and the ss corner (the decode is ~3 gate levels). At 10 MHz SCK one write takes ≈ 1.5 µs.

### Clock-domain crossing rules (firmware)

- **LIF_EN** is 2-FF synchronized into clk (latency 1–3 clk).
- **All other digital-LIF fields** (LIF_SRC, LIF_SR, LIF_EL/VTH/VRST/W) are used without synchronization: change them **only while LIF_EN = 0**. Sequence: write LIF_CTL with LIF_EN = 0, wait ≥ 3 clk, write parameters, write LIF_CTL with LIF_EN = 1. (While disabled the LIF holds V = EL, ref = 0 and clears its pending input, so mux-switch glitches are discarded.)
- Rewriting a byte with an unchanged field does not disturb that field (a transparent latch fed the same value).
- **Probe:** no on-chip break-before-make. To move the probe: write PROBE with EN = 0 and the *old* SEL/SUB, then EN = 0 with the new SEL/SUB, then EN = 1. (Changing EN and SEL in one write could briefly enable the new tap before the old one is off.) The row lines `probe_rsel` follow SEL even while EN = 0; only the column enables, `probe_sel_d1` and `probe_sel_adex` are gated.
- **Bias codes:** a current-DAC code can straddle two bytes (§3.2), so one code change can take two writes with an intermediate code in between. Set BIAS_EN = 0 while changing bias codes (`docs/08 Updated Plan.md` §8), or accept the intermediate value.

## 3. Map (5-bit address, 23 bytes)

| Addr | Name | Bits | Meaning |
|---|---|---|---|
| 0x00..0x04 | IDAC | 40-bit word, LSB first | **Analog.** Eight 5-bit current-DAC codes, code k = word[5k+4 : 5k]; 0 = off (§3.2) |
| 0x05 | VDAC | [5:0] | **Analog.** Voltage-DAC code (6 bit); [7:6] no storage |
| 0x06 | ANA | [3:0] GRP_EN | **Analog.** Group enables |
| | | [4] PLATEAU_EN | **Analog.** D1 plateau enable |
| | | [5] D1_CHAIN | **Analog.** D1 subunit topology: 0 star, 1 chain |
| | | [6] BIAS_EN | **Analog.** Master bias enable (`bias_en`); also gates `ua0_int` |
| | | [7] D1_BSEL | **Analog.** Stim B steering into the dendrite: 0 clustered into d1, 1 distributed into d2 |
| 0x07 | PROBE | [3:0] PROBE_SEL | Spike channel k (0..15) whose neuron is probed (§3.1) |
| | | [5:4] PROBE_SUB | **Analog.** Array slots: 0 membrane, 1 secondary node; D1 / AdEx: tap select (`probe_sub_raw`); 3 = REF follower (slot (0,0), whatever SEL is) |
| | | [6] PROBE_EN | **Analog.** Probe enable (gates the column lines, the D1 line and the AdEx line) |
| 0x08 | MODE | [1:0] UA0_MODE | **Analog.** ua[0]: 0 EXT ÷1 (reset), 1 EXT ÷16, 2 STIM, 3 INT_MON (§3.2) |
| | | [2] OUT_MUX | 0: uio[6] = LIF spike, uio[7] = echo; 1: uio[7:6] = neurons 15:14 |
| | | [3] IB_X2 | **Analog.** `ib_x2`: R1 bias 4 → 8 µA (×2) |
| | | [7:4] RT_EN | `rt_out` = `ui_in[6:3]` & RT_EN (bit 0 stim A, 1 stim B, 2 hold, 3 mem reset) |
| 0x09 | LIF_CTL | [0] LIF_EN | Digital LIF enable (2-FF synchronized) |
| | | [2:1] LIF_SRC | LIF input event: 0 ui3 stim A, 1 ui4 stim B, 2 DC (weight added every tick), 3 analog neuron 0 spike |
| 0x0A | LIF_SR | [3:0] SHIFT, [7:4] REFR | Leak shift *s* (a = 1 − 2^−s); refractory ticks 0..15 |
| 0x0B | LIF_EL | [7:0] | EL = code << (W − 8) |
| 0x0C | LIF_VTH | [7:0] | Vth = code << (W − 8) |
| 0x0D | LIF_VRST | [7:0] | Vreset = code << (W − 8) |
| 0x0E | LIF_W | [7:0] | Input weight in LSB units (unscaled) |
| 0x0F..0x16 | TRIM0..7 | [3:0] nibble 2k, [7:4] nibble 2k+1 | **Analog.** 4-bit trim nibble n at byte 0x0F + n/2, nibble n%2. Only nibbles in `TRIM_MASK` (default 0, 2–8, 14, 15) have storage (§3.3) |

Spare (no storage): VDAC[7:6], PROBE[7], LIF_CTL[7:3], trim nibbles 1 and 9–13 (0x0F [7:4], 0x13 [7:4], 0x14 and 0x15 entirely; §3.3).
Stored bits: 40 IDAC + 6 VDAC + 8 ANA + 7 PROBE + 8 MODE + 3 LIF_CTL + 40 LIF + 4 × 10 trim = **152 latches** (TRIM_MASK = 16'hFFFF: 176).

### 3.1 Probe lines (row × column)

The neuron array is 4 rows × 4 columns (row 0 = bottom). PROBE_SEL keeps meaning "spike channel k"; the macro maps k to its slot. The table is `floorplan/floorplan.py` `slot_map()` / `SPIKE_CH` (the tests derive their model from it):

| PROBE_SEL | 0 S1 | 1 F1 | 2 H1 | 3 AdEx | 4 S2 | 5 F2 | 6 H2 | 7 P2 | 8 S3 | 9 F3 | 10 H3 | 11 P3 | 12 CMP | 13 D1 | 14 AH50 | 15 AH800 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| (row, col) | 0,1 | 1,2 | 0,2 | — | 1,3 | 2,3 | 1,0 | 2,0 | 3,0 | 3,1 | 2,1 | 3,2 | 1,1 | — | 2,2 | 3,3 |

Slot (0,0) is REF (no spike channel); PROBE_SUB = 3 selects it whatever SEL is. **Slot (0,3) is a dummy** (no spike channel, no probe index): no SEL/SUB combination selects it (tested exhaustively).

| Port | Value |
|---|---|
| `probe_rsel[3:0]` | one-hot row of the selected slot (0 for D1 and AdEx); not gated by PROBE_EN |
| `probe_en_c[3:0]` | PROBE_EN & (column of the selected slot == c) |
| `probe_sub`, `probe_sub_b` | PROBE_SUB[0] and its complement (vm/vr tap in the array slots) |
| `probe_sel_d1` | PROBE_EN & (SEL == 13) & (PROBE_SUB != 3) |
| `probe_sel_adex` | PROBE_EN & (SEL == 3) & (PROBE_SUB != 3) |
| `probe_sub_raw[1:0]` | PROBE_SUB. D1 uses it directly; AdEx: 0 membrane, 1 adaptation node |

A slot's switch is `probe_rsel[row] & probe_en_c[col]`, so at most one slot, D1 or AdEx is enabled. Reset: no column enabled, D1 and AdEx off (`probe_rsel` = 0001, the row of channel 0).

|---|---|---|---|---|
| 0 | [4:0] | 0x00 [4:0] | `i0_b0..b4` | `vbn_leak` (leak) |

| 3 | [19:15] | 0x01 [7], 0x02 [3:0] | `i3_b0..b4` | `vbn_ax` (D1 axial) |
| 4 | [24:20] | 0x02 [7:4], 0x03 [0] | `i4_b0..b4` | `vbp_w` (AdEx adaptation increment) |

Firmware: `word = sum(code[k] << 5k)`, then write bytes 0x00..0x04 = word >> 8i (`test/regmap.py` `idac_word`). b0 / c0 = LSB.

| Port | Value |
|---|---|
| `<dac>_b0..b4` | current-DAC code bits 0..4, passed through (0 = off) |
| `<vdac>_c0..c5` | voltage-DAC code bits 0..5, passed through |
| `ua0_s0` | (M == 0) \| (M == 3), M = UA0_MODE |
| `ua0_s1` | M == 1 |
| `ua0_stim` | M == 2 |
| `ua0_int` | M[1] & BIAS_EN |
| `bias_en` | BIAS_EN |
| `ib_x2` | IB_X2 |

Every code bit is a latch output on the port net itself (no logic). After reset every code is 0 (off), `ua0_s0` = 1 (EXT ÷1, master diode), `ua0_int` = 0, `bias_en` = 0: the B1 power-up-safe state. BIAS_EN does not change the codes; bias_b1 uses `bias_en` itself.

## 4. Digital LIF (bit-serial)

Update rule, per accepted tick (same order as `model/reference.py` `LIF.simulate`):

```
if ref > 0:  V = VRST; ref -= 1
else:        Vn = clamp(V + ((EL - V) >>> SHIFT) + (input ? W : 0), 0, 2^W - 1)
             if Vn >= VTH: spike; V = VRST; ref = REFR   else V = Vn
```

- **Tick:** `ui_in[7]` → 2-FF sync → rising-edge detect → 1-clk tick, 2–3 clk after the pin edge. Keep ui7 high ≥ 2 clk and low ≥ 2 clk. An update occupies 2W + SHIFT + 7 clk (≤ 46 clk at W = 12); **ticks during an update are dropped**, so space ticks ≥ 48 clk (64 used in the tests). There is no on-chip prescaler: the PIO generates ticks (fixed rate, or single-step).
- **Input event:** the LIF_SRC-selected line clocks a toggle flop (captures any pulse ≳ 1–2 ns, e.g. a short analog spike), which is 2-FF synchronized; one 1-clk event per rising edge. Events must be ≥ 3 clk apart (two edges inside 2 clk cancel). At most one weight is added per tick (pending flag), as in rev B.
- **Datapath:** W + 2 bits, LSB first (P1: D = EL − V; arithmetic shift; P2: Vn = D + V + W with bit-serial compare). Overflow forces a spike (equals saturation).
- **Output:** the spike (1-clk pulse, a flop output) is on uio[6] when OUT_MUX = 0. There is no read-back of V; the tests check V against the bit-exact model through the hierarchy.
- **Mapping to the analog model:** a = 1 − 2^−s = exp(−dt/τ), V∞ = EL + W·2^s, dt = one tick.

| Domain | Contents |
