## Rev C (2026-11-19): fixed-range DACs, hybrid voltage path (docs/08 Updated Plan.md s4)

### C.1 What changed

| Block | Rev C | Why |
|---|---|---|
| Range selection | **Gone.** `bias_rangegen` (2 x 19-node ladders, 12 range diodes) is replaced by `bias_ladder`: two short R-2R ladders (n: nodes 0..6, p: nodes 0..5) with one fixed tap per DAC, 5 tap diodes + followers | Speed S is now set by the ua[0] reference; one range per DAC is enough. 36 decoded range lines are gone |
| Current DACs | 5 x 5-bit (`idac_p` for vbn lines, `idac_n` for vbp lines), range mux removed; code 0 = off | plan s4 |
| `vbp_st` | fixed: I_nd/16 sink (one master unit) into `rx_p05` -> ~2 x I_nd/16 per detector | plan s4 |
| Voltages | **Resistor-chain DACs fed by a V-to-I converter** (`bias_vi` + 4 x `vdacr_*`): el, vreset_src, vth_cmp (5 bit) and vth_ref (6 bit). The 64-tap string and the `vdac6` tree are gone (see C.4) | ua[0]-independent, ratio-accurate, ~4k um^2 smaller |
| `vbn_prb`, `ib_r1` (`ib_x2`), internal master reference | now copies of the V-to-I current (speed-independent) | at S = 10 a master-ratioed ib_r1 would be 50 nA; R1 and the probe followers need ~4 uA / ~1 uA at every speed |
| `ib_t2` | removed (Tier 2 cut; AdEx uses the shared lines + `vbp_w`) | plan s3 |
| Kept | ESD on ua[0] (1 kOhm + 2 clamps), the 4 UA0 modes, the /16 pre-mirror, BIAS_EN safe power-up, `bias_rails` (shifted-source rails + ladder gate biases), receivers | |

### C.2 Speed: reference current

S = 100 x I_nd / 1 uA (I_nd = current in the 16-unit master diode; ladder input I_in = I_nd/16 <= 0.63 uA).

| S | I_nd | Iref, EXT /1 (mode 0) | Iref, EXT /16 (mode 1) | ua[0] pad voltage /1 (tt 27 C) |
|---|---|---|---|---|
| 10 | 0.1 uA | 0.1 uA | 1.6 uA | 0.50 V |
| 100 | 1 uA | 1 uA | 16 uA | 0.60 V |
| 1000 | 10 uA | 10 uA | 160 uA | 0.74 V |

INT modes (2 STIM, 3 INT_MON): I_nd = the ~1 uA V-to-I copy -> S ~ 80 / 97 / 122 (ss / tt / ff, 27 C).

**Leakage at S = 10 / 85 C:** code 1 of every DAC is within 0.7 % of 1/16 of its code-16 current (ideal 1.000) at all 15 corner/temperature cases; the code-0 floor is <= 37 fA against a smallest LSB of ~7 pA (vbn_ax at S = 10). The S = 10 end clears 85 C leakage by more than two decades, so the scale could even be pushed lower.

**Scaling linearity** (code 16, relative to an exact 1:10 scaling from S = 100; 15 corner/temperature cases):
- n-ladder lines (vbn_leak, vbn_ref, vbn_ax): 0.96-1.01 at S = 10 and 0.92-1.00 at S = 1000.
- p-ladder lines (vbp_syn, vbp_w): 1.04-1.08 at S = 10 and **0.79-0.84 at S = 1000**. This is a systematic, corner-independent compression of the p-ladder / nfet tap diodes at I_in = 0.63 uA, the same trend rev B showed at high I_nd.
- So at S = 1000 the synapse and adaptation codes run ~20 % low. FS is 2-4 x the nominal current, so the code absorbs it (per-speed calibration, plan s8).
- Two corner fixes came out of this check (both in the rev C netlist):
  - The tap followers are now biased from the shifted rails (BP from vsp, BN from vsn). Before, a vdd-referenced follower bias made the follower Vsg so large at fs/0 C that the n-ladder tap shunt went into triode: vbn_ref scaled only 0.46x at S = 1000.
  - idac_n switch level is vgln (1.8 V) instead of vglp. vglp left the units too little Vds at ss/0 C, giving a -1.05 LSB MSB step on vbp_w at S = 1000; the vbp lines sit at 2.3-2.7 V, so vgln costs no compliance.

**EXT /16 vs EXT /1** at equal I_nd: +2 / +5 / +12 % at S = 1000 / 100 / 10 (tt; ss +1 / +4 / +10 %, ff +2 / +6 / +14 %). The 16:1 pre-mirror gains at low current. Use EXT /1 for S <= 100 when absolute speed matters.

| Line (code bits) | DAC / tap | Receiver | LSB at S = 100 | FS (code 31) | Nominal -> code |
|---|---|---|---|---|---|
| `vbn_leak` (i0) | idac_p, vgp5 | rx_n4 | 132 pA | 4.10 nA | 1.3 nA line (324 pA / tail) -> ~10 |
| `vbn_ref` (i1) | idac_p, vgp3 | rx_n2 | 483 pA | 15.0 nA | 6.8 nA -> ~14 |
| `vbp_syn` (i2) | idac_n, vgn5 | rx_p24 | 142 pA | 4.42 nA | 1 nA -> ~7 |
| `vbn_ax` (i3) | idac_p, vgp6 | rx_n1 | 69.5 pA | 2.15 nA | 647 pA -> ~9 |
| `vbp_w` (i4) | idac_n, vgn3 | **rx_p05** (pfet 1/4) | 512 pA line = **1.02 nA in the AdEx 1/2 device** | 31.8 nA (AdEx side) | AdEx track: 0.5-30 nA at S = 100 -> codes 1-29; 8 nA -> ~8 |
| `vbp_st` | fixed I_nd/16 | rx_p05 | | 69 nA line (~138 nA per detector) | |

`vbp_w`: the AdEx track asked for 0.5-30 nA at S = 100 (~1 nA LSB). The DAC sits on tap vgn3 (512 pA LSB) and its receiver is `rx_p05` (pfet 1/4) instead of `rx_p1`, so the AdEx XPW (1/2) mirrors the line 2:1. The 2:1 comes from L (4 vs 2 um), so expect a few % ratio error; it is calibrated with the rest. AdEx: rename its `vbp_adw` pin to `vbp_w`. All 5 x 15 corner/temperature sweeps are monotonic; LSB spread over corners and temperature is -6 / +13 % around tt 27 C (worst: vbp_syn and vbp_w at ff 85 C).

### C.4 Voltage path (hybrid)

- **Reference tap:** `vglp` of the existing rails string (VDD x 4/11 = 1.19 V; ratiometric, en-gated). The plan's "fixed string tap" is this node, so no second string is needed.
- **`bias_vi`:** a 5T OTA (nfet pair, self-biased tail ~0.3 uA, start-up that only acts while the tail is off and BIAS_EN = 1) forces vglp across R0 = 58.5 kOhm through M_out (pfet 16/2) + cascode (16/1, gate vglp): I_vi ~20 uA. Identical cascoded copies source I_vi into `el`, `vreset_src`, `vth_cmp`; a 1:4 copy feeds `vth_ref`; 0.8/2 copies make `vbn_prb` (~1 uA into a 2/2 diode), `ib_r1` (4 x 2/2 on vbn_prb, +4 with ib_x2) and the internal master reference `iint`.
- **`vdacr_*`:** out - R_base - binary segments r, 2r, ... - vss; segment b is shorted by an nfet when bit b = 0. V = V(vglp) x k x (R_base + code x r)/R0: one resistor type throughout, so the output is a resistor ratio times VDD. Monotonic by construction (each step adds r - R_on > 0).
- **Why not the string + `vdac6` tree for vth_ref:** a 6.35 mV tap needs ~330 Ohm segments. With the `ppolyf_u_1k` model, each terminal adds 85 Ohm*um/W with a -0.79 %/K tempco, so short segments are 12-40 % terminal resistance and the window drifts with temperature. Routing 64 taps to the tree is also what blocked rev B's `bias_vblk`. The chain DAC has the same function (6 bit, ratiometric to VDD, monotonic, 0.35-0.75 V) and saves the string (~1.4k) and the tree (2.5k um^2). The port (`v0_c0..c5` -> `vth_ref`) is unchanged.

| Output (code bits) | Range (tt 27 C) | LSB | DNL (all corners) | Corner/T spread of the endpoints |
|---|---|---|---|---|
| `el` (r0, 5 bit) | 0.994-1.618 V | 20.1 mV | -0.16 / +0.58 LSB | code 0: 0.992-0.997 V; code 31: 1.607-1.623 V |
| `vreset_src` (r1) | 0.891-1.514 V | 20.1 mV | -0.16 / +0.59 LSB | 0.888-0.894 / 1.504-1.519 V |
| `vth_cmp` (r2) | 1.094-1.507 V | 13.3 mV | -0.21 / +0.69 LSB | 1.092-1.097 / 1.496-1.512 V |
| `vth_ref` (v0, 6 bit) | 0.350-0.750 V | 6.35 mV | -0.17 / +0.28 LSB | 0.349-0.351 / 0.746-0.752 V |

- **Independence of ua[0]:** Iref swept over 0 / 0.1 / 1 / 10 uA (EXT /1): every code of all four outputs moves by <= 0.58 mV (<= 0.05 LSB). The residue is the current-DAC return current loading the shared rails string at S = 1000 FS; it is 0 at the other corners within print resolution.
- **VDD:** outputs scale with VDD (ratiometric), e.g. at VDD 2.97 / 3.63 V el spans 0.894-1.453 / 1.094-1.779 V and vth_ref 0.315-0.674 / 0.385-0.825 V (exactly x0.9 / x1.1), still monotonic.
- **DNL** peaks at the half-scale step (+0.25 LSB at 27 C, +0.47 LSB at 85 C, where the switch R_on is larger); never negative beyond -0.21 LSB.
- **Settling / start-up** (bias_b1, 2 pF per output, `run_revc_tran.sh`): after BIAS_EN rises, every output is within 0.5 LSB of its final value in 0.9-1.5 us (ff 85 / tt 27 / ss 0); a full-scale code step (0 -> 31 or 0 -> 63) settles to 0.5 LSB in 0.5-0.9 us (5 bit) and 1.2-1.9 us (vth_ref). Start-up was clean in all three corners.
- **Supply current** (all outputs mid-code, S = 100): 93 / 112 / 142 (ss 0 / tt 27 / ff 85) uA (V-to-I 5 x 20 uA dominates; rev B ~60 uA).
- `ib_r1` = 3.3-3.5 / 4.0-4.2 / 5.0-5.3 uA (ss / tt / ff), x2 with ib_x2; `vbn_prb` diode at 0.62-0.88 V.

### C.5 Safe power-up (BIAS_EN = 0, all codes 0)

As rev B, plus: `bias_vi` holds vgvi at vdd (POFF) and its start-up path is gated by BIAS_EN, so I_vi = 0 and every resistor-DAC output is pulled to 0 V through its chain; vbn_prb is 0 V through its diode; ib_r1 sinks nothing. The ladder taps are 0 with nd at vss. No gate line floats: every current line ends in its receiving diode, every voltage line in a resistor chain to vss.

Leaf sum for the block (5 IDACs, 4 resistor DACs, 6 receivers, master, rails, ladder, V-to-I): **18.8k um^2** (rev B equivalent ~24.6k).

Rules learned:
- ppolyf_u_1k segments need >= 2 um^2 of salicide block (SB.13), so short segments are drawn at W = 2 um.
- The resistor-DAC code inverters use L = 1 um. With 0.28 um gates, a ~300 um top-level Metal3 code line exceeded the Metal3 antenna ratio (ANT.4, 400) in the standalone block. In the chip the control macro's drivers would also discharge these lines.
- Top-level notch fill must not merge a subcell's internal metal. All of it carries one placeholder net, and closing at 0.29 um bridged different leaf nets at minimum spacing. Fixed in `cellgen.fill_notches`; this was the cause of the first top-level LVS failures.

**`bias_b1` assembly** in the integrator's frame: origin tile (80, 12), **265 x 115 um** (tile x 80-345, y 12-127; D1 occupies tile x 8-78).

## Rev B (2026-11-17): what changed and why

| Change | Why |
|---|---|
| All poly resistors are `ppolyf_u_1k` (strings at ~20 µA, built from identical 15 kΩ unit strips) | magic cannot extract `ppolyf_u_3k`, so a 3k string could never be LVS-checked |
| Rail decaps are pfet **accumulation** caps referenced to each rail's own supply (vsn→vss, vsp→vdd), 10 × 10 µm each (~0.2 pF) | the rev A MOS decaps (vsn→vdd, vsp→vss) coupled supply noise straight into the unit gate-source voltage (see re-checks) |
| `bias_master`: fixed ratio m = 1 (I_in = I_nd/16); UA0 modes incl. the **÷16** pre-mirror; internal reference; BIAS_EN; fixed outputs `vbn_prb`, `ib_r1` (×2 option), `ib_t2`; secondary ESD on ua[0] (§4) | ÷16 keeps the ladder input ≤ ~1 µA for Iref up to 256 µA; m was redundant with the external Iref |
| `idac_n/_p`: range one-hot comes decoded from the control macro (active high for n, active low for p); in-cell logic inverters removed | 7 fewer inverters per p-DAC; decoding is a few gates in the macro |
| Polarity mix is now 3 × `idac_p` + 3 × `idac_n` | matches the lines actually needed (3 vbn, 3 vbp incl. `vbp_syn`) |
| New cells `rx_*` (receiving diodes) and the top level `bias_b1` | the DAC outputs become gate-voltage lines inside B1; `bias_b1` is the LVS reference for the B1 layout |

## 1. Re-checks after the MIM → MOS decap swap

All at Iref (I_nd) = 8 µA, victims are an `idac_n` and an `idac_p` at range 3 code 19 (~150–180 pA), outputs held at 1 V. dVgs is the unit gate-source disturbance; 0.35 mV ≈ 1 % of a subthreshold current. Files: `sim/tb/bias/out/recheck/rails_settle_summary.txt`.

**Rail stability, AC (VDD carries the AC):** worst |dVgs| per volt of VDD over 100 Hz–100 MHz.

| rails | n | p | note |
|---|---|---|---|
| rev B (accumulation caps to own supply), tt/ss/ff × 0/27/85 °C | 0.075–0.088 | 0.114–0.125 | ≈ 0.25 / 0.35 % of current per mV of VDD ripple |
| rev A orientation (vsn→vdd, vsp→vss), tt 27 | 0.638 | 0.457 | vsn follows VDD above 1 MHz |
| no decap, tt 27 | 0.091 | 0.121 | |

**VDD step +50 mV in 1 ns:** rev B dVgs peak 5.5 / 3.8 mV (tt), 5.1 / 3.5 (ss 0 °C), 5.8 / 4.4 (ff 85 °C); rev A orientation 33 / 24 mV. Back within 1 % in 24 / 18 µs in every variant: that tail is the ratiometric gate-line settling, not the rails. No ringing anywhere (the rails are passive RC nodes; the only loops are the range-diode followers, which are unchanged).

**Aggressor glitch (6 DACs at range 0 switch 0↔31 together):** rev B dVgs 15.6 / 19.2 mV, n back within 1 % in 0.3 µs, p in 17 µs; 20 µs after the edge the victims are within 0.3 / 0.8 % (tt), 0.4 / 1.2 % (ss 0 °C). No-decap is about 10 % worse, rev A orientation about 20 % better on this one test.

**Conclusion:** rev A's orientation was the wrong one for supply noise (8× worse VDD coupling at HF). Rev B's own-supply accumulation caps are ~2 fF/µm² at 0.3 V bias (vs ~4 in inversion, `cv_moscap.py`), and their benefit over no decap is small (~15 % on the n side), so they are kept small (10 × 10 µm).

**DC regression of rev B** (`out/recheck/idac_corners_revB.txt`: 9 corner/temperature cases, Vout = 1 V):
- LSBs and range steps are as in rev A (3.5 nA … 0.16 pA; steps 6.96–7.93). The leakage floor at code 0 is 8 fA (n) and 5.8 fA (p) at 27 °C.
- 107 of 108 range sweeps are monotonic. **ss 0 °C range 0 idac_n has DNL −1.01 LSB** (rev A worst: −0.99). This is the known zero-margin MSB step, now just over the edge. Range 0 is the coarse range; if it matters, use 8 µm² MSB units (rev A recommendation).

**VDAC** (`out/recheck/vdac_revB.txt`, 15 corners + VDD ±10 %, rev B2 string):
- Monotonic with DNL ≈ 0 everywhere.
- The span is 0.288–2.112 V at tt (gain about 5 % above the 0.309–2.062 V design value, endpoints corner-dependent by ±25 mV). This is a ratiometric offset/gain error of the `ppolyf_u_1k` model's short segments, not a linearity error; it is calibrated with the probe REF channel like the rest.
- Settling into 1 pF + 20 gates is 0.76 µs to 0.5 LSB (tt) and 1.07 µs (ss 0 °C), 3–4× faster than rev A because the string now runs at 20 µA.

## 2. Bias-line allocation

I_nd = 8 µA (ladder input 0.5 µA). Receiving diodes sit in B1 at the DAC outputs; lines leave B1 as gate voltages. D1 shares the array's vbn_leak, vbp_st, vbn_ref, vbn_prb, el, vreset and vsrc; its only own DAC line is vbn_ax.

| Line | Source | Receiver in B1 | Nominal → range (code) | Consumers |
|---|---|---|---|---|
| `vbn_leak` | IDAC0 (`idac_p`) | `rx_n4`: 4 × nfet 2/4 | 320 pA per tail → 1.28 nA line: range 2 (code ~19) | NA leak OTA tails (2/4), D1 (324 pA) |
| `vbn_ref` | IDAC1 (`idac_p`) | `rx_n2`: 2 × nfet 2/4 | 3.4 nA per device → 6.8 nA: range 1 (code ~14) | NA refractory (2/4), D1 |

### What the regmap / control macro needs (rtl owner)

- **IDAC k byte unchanged** ({RANGE[2:0], FINE[4:0]}). The macro decodes RANGE into 7 one-hot lines per DAC: RANGE 1..6 → range 0..5 (range 0 = largest); RANGE 0 and 7 → off. Off is also forced while BIAS_EN = 0. Polarity: IDAC0, 1, 4 (`idac_p`) get **active-low** `i<k>_rb0..rb5`, `i<k>_rboff`; IDAC2, 3, 5 (`idac_n`) get active-high `i<k>_r0..r5`, `i<k>_roff`; plus FINE `i<k>_b0..b4`.
- **VDAC**: `v<k>_c0..c5` as now.
- **Master**: `ua0_s0 = (M==0)|(M==3)`, `ua0_s1 = (M==1)`, `ua0_stim = (M==2)`, `ua0_int = M[1] & BIAS_EN`, `bias_en = BIAS_EN`; new bit `ib_x2` (suggest MODE[3], currently spare).

### Power-up / reset safety

The config is lost whenever the project is deselected, so all-zero must be safe. With BIAS_EN = 0, UA0_MODE = 0, every RANGE = 0:
- `nd` is pulled to vss, so every ladder current is 0. ua[0] still connects to `nd`: an SMU on ua[0] sees ~0 V, not an open pin.
- Both poly strings are off (pfet headers): vsn/vsp/vgln/vglp, every VDAC tap and output sit at 0 V; the VDAC trees at code 0 connect their outputs to tap 0.
- Every IDAC is off (its gate node tied to its own rail, all units off); every current line ends in its diode-connected receiver and `vbn_prb` in its diode, so no gate line floats.
- The internal reference is off (`ua0_int` includes BIAS_EN).
- Condition: the macro's latches must come up cleared (`rst_n` at project select). Until reset, the decode could select anything; that is harmless but not "off".

## 4. Secondary ESD on ua[0]

In `bias_master`: ua[0] → **1 kΩ `ppolyf_u_1k`, W = 4 µm, one square** → inner node `pin` with **`diode_pd2nw_03v3` (pin → vdd) and `diode_nd2ps_03v3` (vss → pin)**, 10 µm² and 22 µm perimeter each. Every pad switch (S0, S1, the stimulus gate) hangs off `pin`. Rev B had 2 kΩ (W = 2) and no clamps.

Compliance therefore improves.
- STIM mode: the stimulus sees 1 kΩ in series (negligible) plus the clamps' reverse leakage, fA at 27 °C and low pA at 85 °C: fine for nA stimuli, a few % for pA stimuli when hot.
- The clamps only conduct beyond vss − 0.6 V / vdd + 0.6 V; the 1 kΩ limits their current during a primary-clamp event.
- Layout: the resistor and both diodes are at the bottom of `bias_master`, next to its `pad` pin, so they sit where ua[0] enters once B1 is assembled; the p+ diode has its own vdd n-well and n-tap, the n+ diode is inside the master's p-tap ring.

# Rev A (2026-11-08): schematic report


## Topology and why (rev A)


- **`bias_master`**: ua[0] → 2 kΩ ppolyf_u_1k → a 16-unit nfet diode (4/2 µm). Two 4-bit outputs give I_in = Iref·m/16, one sinking and one sourcing (through a p-mirror).
- **`bias_rangegen`**: two Bult-Geelen MOS R-2R ladders, one n and one p. Each has 19 sections and taps every 3 halvings, giving six ranges in ×8 steps.
  - Each tap feeds an 8-unit diode whose drain is boosted by a source follower. That keeps Vds ≈ 0.5 V on the diode even when its Vgs is ≤ 0.
  - Without the follower, the range-5 diode collapsed into triode at ff/85 °C and gave 2.6× too much current.
  - The follower also makes the 12 gate lines low-impedance.
- **`bias_rails`**: a 10 µA poly string sets the shifted-source rails vsn ≈ 0.30 V and vsp ≈ 3.00 V, plus the ladder gate biases (1.8 V and 1.2 V). Each rail has 1 pF of MIM decoupling.
- **`idac_n` / `idac_p`**: a one-hot range mux plus 31 unit devices (2/2 µm, 4 µm²) on the shifted rail, steered by 5 bits.
  - The steering switch gates swing only to a cascode level (vcas). This keeps the unit drains fixed in both states, which gives flat compliance and no slewing on a code change.
  - LSB = I_in/128/8^r.
- **`vref_string64` + `vdac6`**: one shared ratiometric ppolyf_u_3k string (3.3 µA, 0.30–2.00 V) plus a 6-level nfet tree per output. There is no buffer.
  - I chose this over current×R because it is monotonic by construction and independent of Iref, resistor corner and temperature.
- **`trim4_p` / `trim4_n`**: I = I_ref·(8+c)/16, so 0.5×–1.44×. There are 8 always-on units plus 1/2/4/8 switched units (1/2 µm). `trim_ref_*` is the shared 16-unit diode.

## What fails or is weak

1. **Vreset line.** 20 × 200 fF membranes reset from 1.5 V push the line up by 715 mV, and after a 2 µs pulse it is still 86 mV high.
   - EL and Vth are fine unbuffered.
   - Vreset needs a buffer, a reset pulse longer than about 10 µs, or local hold caps.
2. **High master current.** With Iref = 100 µA and m = 1 (I_in = 6 µA), range 0 compresses by 9 % and the range ratios drift by about 20 %.
   - Iref = 20 µA with m = 1 is about 9 % low.
   - Iref = 1 µA with m = 8 is as good as nominal.
   - In practice, keep I_in ≲ 1 µA.
3. **Absolute accuracy.** It is about ±10 % from corners, and there is about 10 % die-common σ on top. Plan to calibrate per die, for example by measuring τ.
4. **DNL margin.** A worst DNL of −0.99 LSB means monotonicity will not be guaranteed across many dies.
5. **Settling.** Millisecond settling and slow start-up are inherent at 150 pA.

## Recommendations

- Add a /16 option to the master, or a second ratio, for Iref > 20 µA.
- Buffer Vreset; a 5T OTA follower at about 1 µA is enough.
- Don't use code 0 as "off" on live lines. Use `roff`, or precharge the line.
- Shrink the master units to 4 µm² (saves about 900 µm²).
- If monotonicity margin matters, use 8 µm² units for the MSB.
- Have C1 supply the one-hot range decoding.
- Re-verify after PEX: the ladder nodes at fA are sensitive to junction and wiring leakage.
