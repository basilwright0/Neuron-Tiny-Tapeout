# B1 shared bias generator: schematic report (2026-11-08)

Netlists are in `cells/bias/` (generated by `gen_cells.py`; port lists are in each `.subckt` header). Testbenches are in `sim/tb/bias/` (`run_all.sh`; summaries in `out/*.txt`). Everything is schematic-level, with no layout parasitics.

## Topology and why

- **`bias_master`**: ua[0] → 2 kΩ ppolyf_u_1k → a 16-unit nfet diode (4/2 µm). Two 4-bit outputs give I_in = Iref·m/16, one sinking and one sourcing (through a p-mirror).
- **`bias_rangegen`**: two Bult-Geelen MOS R-2R ladders, one n and one p. Each has 19 sections and taps every 3 halvings, giving six ranges in ×8 steps.
  - Each tap feeds an 8-unit diode whose drain is boosted by a source follower. That keeps Vds ≈ 0.5 V on the diode even when its Vgs is ≤ 0.
  - Without the follower, the range-5 diode collapsed into triode at ff/85 °C and gave 2.6× too much current.
  - The follower also makes the 12 gate lines low-impedance.
- **`bias_rails`**: a 10 µA poly string sets the shifted-source rails vsn ≈ 0.30 V and vsp ≈ 3.00 V, plus the ladder gate biases (1.8 V and 1.2 V). Each rail has 1 pF of MIM decoupling.
- **`idac_n` / `idac_p`**: a one-hot range mux plus 31 unit devices (2/2 µm, 4 µm²) on the shifted rail, steered by 5 bits.
  - The steering switch gates swing only to a cascode level (vcas). This keeps the unit drains fixed in both states, which gives flat compliance and no slewing on a code change.
  - LSB = I_in/128/8^r.
- **`vref_string64` + `vdac6`**: one shared ratiometric ppolyf_u_3k string (3.3 µA, 0.30–2.00 V) plus a 6-level nfet tree per output. There is no buffer.
  - I chose this over current×R because it is monotonic by construction and independent of Iref, resistor corner and temperature.
- **`trim4_p` / `trim4_n`**: I = I_ref·(8+c)/16, so 0.5×–1.44×. There are 8 always-on units plus 1/2/4/8 switched units (1/2 µm). `trim_ref_*` is the shared 16-unit diode.

## Results

**idac LSB (tt, 27 °C, Iref = 8 µA, m = 1).** All 27 corner/temperature/Vout cases are monotonic in every range.

| range | LSB n / p | span (codes 1–31) | corner+temp spread of LSB |
|---|---|---|---|
| 0 | 3.5 n / 3.75 n | 3.5–109 nA | −7/+9 % |
| 1 (10 nA: code 20) | 480 p / 530 p | 0.48–15 nA | −8/+11 % |
| 3 (150 pA: code 16–17) | 9.2 p / 9.9 p | 9–285 pA | −10/+16 % |
| 4 (10 pA: code 8) | 1.2 p / 1.3 p | 1.2–37 pA | −11/+20 % |
| 5 (stretch) | 0.16 p / 0.18 p | 0.16–4.9 pA | −13/+35 % (85 °C) |

- **Range steps:** the ladder steps are 6.8–7.9 instead of 8. This is a systematic error of the BSIM model's split ratio (about 1.93 per halving even with ideal terminals) and it is corner-stable.
- **Leakage floor** (code 0, Vout 0.5–2.5 V): n = 8.6 fA and p ≤ 51 fA at 85 °C; ≤ 41 fA at 27 °C.
- **Shifted source matters.** At ff/85 °C with vsn = 0 / vsp = 3.3 V, range 4 code 1 gives 9.3 pA (wanted 1.4) and range 5 gives 9.4 pA (wanted 0.2). With the shift the values are correct.
- **Compliance:** within ±2 % for n over 0.45–3.1 V (0.6 V at ff/85 °C on range 4) and for p over 0.2–2.85 V. Across 0.5–2.5 V, I(0.5 V)/I(1 V) ≥ 0.976.

**Mismatch MC** (50 dies × 2 instances per polarity, tt, 27 °C):

| | code 1 | code 16–20 | code 31 |
|---|---|---|---|
| σ/I between instances on one die | 6–8 % | 1.3–1.7 % | 1.1 % |
| σ/I die-common (ladder, diodes, master) | 9–13 % | 7–12 % | 7–11 % |

- Monotonic in 100/100 instances on ranges 1, 3 and 4.
- Worst DNL is −0.99 LSB (median −0.22), so monotonicity has essentially no margin.

**Settling at 150 pA** (range 3, code 18→19). The load is a 16-unit receiving diode with 1 pF + 20 trim cells.

| case | to 5 % | to 1 % |
|---|---|---|
| tt | 1.7 ms | 2.9 ms |
| ff | 1.6 ms | 2.6 ms |
| ss | 1.7 ms | 2.5 ms |
| 0.2 pF line | 1.2 ms | 2.1 ms |
| code 19→9 | 2.3 ms | 3.3 ms |
| idac output held at 1 V (DAC alone) | ≈10 µs, apart from a slow drift of about 4 % over 1 ms | — |

- This is the receiver pole, C·nU_T/I, which is inherent to a subthreshold line.
- Starting from code 0 (an empty line) is slew-limited: only 144 pA after 12 ms.
- Transient spikes of +50 % last much less than 10 µs. They are charge injection.

**vdac** (15 corner/temperature cases plus VDD ±10 %):
- Monotonic, DNL ≈ 0, and within 7.5 mV of ideal. The output scales with VDD.
- Into 1 pF + 20 gates it settles to 0.5 LSB in 2.8 µs (tt) and 3.5 µs (ss, 0 °C).

**trim4_p** (corners at 100 pA / 1 nA / 1 µA): gain is 0.505–0.516 at code 0, 1.006–1.031 at code 8 and 1.446–1.482 at code 15, and monotonic everywhere.
- MC (200 cells): σ(g) is 3.3 % at 100 pA–1 nA and 1.8 % at 1 µA. σ of one LSB step is 1.1 % against the 6.25 % nominal step.

- **Example build** (core + 4 n-idacs + 2 p-idacs + 3 vdacs): ≈ 10,200 µm², plus 16 trims ≈ 2,700 µm².
- **Supply current:** about 15 µA from VDD plus Iref.

## What fails or is weak

1. **Vreset line.** 20 × 200 fF membranes reset from 1.5 V push the line up by 715 mV, and after a 2 µs pulse it is still 86 mV high.
   - EL and Vth are fine unbuffered.
   - Vreset needs a buffer, a reset pulse longer than about 10 µs, or local hold caps.
2. **High master current.** With Iref = 100 µA and m = 1 (I_in = 6 µA), range 0 compresses by 9 % and the range ratios drift by about 20 %.
   - Iref = 20 µA with m = 1 is about 9 % low.
   - Iref = 1 µA with m = 8 is as good as nominal.
   - In practice, keep I_in ≲ 1 µA.
3. **Absolute accuracy.** It is about ±10 % from corners, and there is about 10 % die-common σ on top. Plan to calibrate per die, for example by measuring τ.
4. **DNL margin.** A worst DNL of −0.99 LSB means monotonicity will not be guaranteed across many dies.
5. **Settling.** Millisecond settling and slow start-up are inherent at 150 pA.

## Recommendations

- Add a /16 option to the master, or a second ratio, for Iref > 20 µA.
- Buffer Vreset; a 5T OTA follower at about 1 µA is enough.
- Don't use code 0 as "off" on live lines. Use `roff`, or precharge the line.
- Shrink the master units to 4 µm² (saves about 900 µm²).
- If monotonicity margin matters, use 8 µm² units for the MSB.
- Have C1 supply the one-hot range decoding.
- Re-verify after PEX: the ladder nodes at fA are sensitive to junction and wiring leakage.
